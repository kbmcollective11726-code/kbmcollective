### High Findings (Should Fix Before Launch)

#### H1 — Password policy still min 8 — **deferred by product**
1. **SEVERITY:** High (ASVS) / Accepted until revisit  
2. **LOCATION:** `app/(auth)/register.tsx:47-48`; `app/(auth)/change-password.tsx:53-54`; `admin-setup/public/auth-recovery.js:117-118`; Edge reset/admin paths  
3. **ISSUE:** Minimum password length is 8, not ASVS ≥12. No complexity / denylist.  
4. **IMPACT:** Weaker resistance to stuffing / guessing.  
5. **FIX:** Enforce ≥12 on every create/reset path; set Supabase Auth min length to match.

#### H2 — TOTP MFA unwired for cadmin — **deferred**
1. **SEVERITY:** High  
2. **LOCATION:** `admin-setup/src/pages/LoginMfa.tsx` (orphaned); `admin-setup/src/App.tsx` (email OTP only)  
3. **ISSUE:** Platform and event admins get **email OTP** step-up; TOTP helpers exist but are not routed.  
4. **IMPACT:** Email OTP is better than password-only; TOTP still missing for ASVS MFA depth.  
5. **FIX:** Route TOTP for privileged roles; enforce server-side where possible.

#### H3 — Mobile dependency highs (Expo toolchain)
1. **SEVERITY:** High  
2. **LOCATION:** `docs/security-audits/2026-09-01-deps-preflight.md` — mobile **8 High** (`image-size` via metro), **17 Moderate**  
3. **ISSUE:** Advisories in dev/build toolchain (metro/expo-router), not runtime app logic.  
4. **IMPACT:** DoS in dev/build contexts; schedule Expo SDK major to clear.  
5. **FIX:** Expo SDK bump on QA calendar; accept until then per `DEPENDENCY-ADVISORY-PLAN.md`.

### Medium Findings (Fix within 30 days)

#### M1 — Public R2 object URLs for feed assets — **accepted**
Product choice for live feed CDN URLs. Documented in prior audits.

#### M3 — Co-member can SELECT email/phone — **by design**
Networking product requirement. Document retention in `PII-RETENTION.md`.

#### M5 — Security Advisor DEFINER EXECUTE grant noise
Many `SECURITY DEFINER` RPCs broadly executable to `authenticated`. Review and narrow grants over time.

#### M9 — Storage / registration uploads bypass R2 magic-byte validators
Mobile Storage paths may not use `upload-image-to-r2` proxy validation.

#### M10 — `push_token` column SELECT re-granted (**new / regression**)
1. **SEVERITY:** Medium  
2. **LOCATION:** `supabase/migrations/20260821013000_grant_push_token_select_legacy_star.sql:4`  
3. **ISSUE:** `GRANT SELECT (push_token) ON users TO authenticated` restores column access for legacy `select=*` queries. RLS still limits rows, but co-members in an event can read peers' push tokens if the column is selected.  
4. **IMPACT:** Push token harvesting among co-attendees on old app builds.  
5. **FIX:** Ship app builds using `get_my_user_profile` only; revoke column grant when Play/App Store adoption is high; or RPC that omits `push_token` for peer reads.

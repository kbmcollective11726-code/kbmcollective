### High Findings (Should Fix Before Launch)

#### H1 — Password policy still min 8 — **deferred by product**
1. **SEVERITY:** High (ASVS) / Accepted until revisit  
2. **LOCATION:** `app/(auth)/register.tsx:46-47`; portals `minLength={8}`; Edge `admin-reset-user-password`, `bulk-create-users`  
3. **ISSUE:** Minimum password length is 8, not ASVS ≥12. Advisor: `auth_leaked_password_protection`.  
4. **IMPACT:** Weaker resistance to stuffing / guessing.  
5. **FIX:** Enforce ≥12 + complexity; enable leaked-password protection in Supabase Auth.

#### H2 — Event-admin MFA unwired — **deferred**
1. **SEVERITY:** High  
2. **LOCATION:** `admin-setup/src/App.tsx:207-217` (non–platform-admin skips OTP)  
3. **ISSUE:** Platform admins get email OTP; event admins are password-only. Advisor: `auth_insufficient_mfa_options`.  
4. **IMPACT:** Stolen event-admin password → event console control.  
5. **FIX:** Require OTP/TOTP for all cadmin privileged roles.

#### H3 — Mobile / live-wall dependency highs
1. **SEVERITY:** High  
2. **LOCATION:** `docs/security-audits/2026-08-02-deps-preflight.md` — mobile **6 High**, live-wall **3 High**, admin-setup **2 Moderate**  
3. **ISSUE:** Expo path to clean audit is SDK major (`audit fix --force` breaking). Next 15.5.22 still pulls transitive postcss/sharp advisories.  
4. **IMPACT:** Supply-chain / tooling risk; many Metro/postcss issues limited runtime exploitability.  
5. **FIX:** `DEPENDENCY-ADVISORY-PLAN.md`; scheduled Expo major QA.

### Medium Findings (Fix within 30 days)

#### M1 — Public R2 object URLs
1. **SEVERITY:** Medium (accepted for feed assets)  
2. **LOCATION:** Cloudflare R2 public URLs  
3. **ISSUE:** URLs shareable if leaked.  
4. **IMPACT:** Unauthorized media view if URL obtained.  
5. **FIX:** Document threat model; signed URLs for sensitive assets.

#### M2 — Client-shipped `LOG_AUTH` secret (obscurity)
1. **SEVERITY:** Medium  
2. **LOCATION:** `EXPO_PUBLIC_LOG_AUTH_ATTEMPT_SECRET` / `VITE_LOG_AUTH_ATTEMPT_SECRET`  
3. **ISSUE:** Secret extractable from client builds; not in committed `eas.json`. EAS project env / production OTA still needed so mobile builds ship the secret.  
4. **IMPACT:** Can invoke rate-limit / auth-log Edge APIs (not full auth bypass).  
5. **FIX:** EAS env + `npm run update:production` after `eas login`; longer-term Auth hooks / server-only.

#### M3 — Co-member can SELECT email/phone (networking by design)
1. **SEVERITY:** Medium / Partial accept  
2. **LOCATION:** `users` RLS for event co-members; live `auth_email_select=true`  
3. **ISSUE:** Email/phone readable among co-members.  
4. **IMPACT:** PII within event trust boundary.  
5. **FIX:** Product decision — document or narrow.

#### M5 — Security Advisor DEFINER EXECUTE noise
1. **SEVERITY:** Medium (residual)  
2. **LOCATION:** Advisor **112 WARN** / **7 INFO** — DEFINER executable ×86 authenticated + ×24 anon; includes intentional live-wall RPCs  
3. **ISSUE:** Large DEFINER surface if any body lacks authz.  
4. **IMPACT:** Privilege abuse if a DEFINER is under-checked.  
5. **FIX:** Continue grant minimization; document intentional anon live-wall RPCs.

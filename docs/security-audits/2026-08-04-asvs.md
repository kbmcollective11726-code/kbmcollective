### High Findings (Should Fix Before Launch)

#### H1 — Password policy still min 8 — **deferred by product**
1. **SEVERITY:** High (ASVS) / Accepted until revisit  
2. **LOCATION:** `app/(auth)/register.tsx:46-48`; `admin-setup/src/lib/adminResetUserPassword.ts:29-30`; `supabase/functions/admin-reset-user-password/index.ts:66-68`; `supabase/functions/bulk-create-users/index.ts:156-157`  
3. **ISSUE:** Minimum password length is 8, not ASVS ≥12. No complexity / denylist in app or Edge.  
4. **IMPACT:** Weaker resistance to stuffing / guessing (worse with event-admin password-only).  
5. **FIX:** Enforce ≥12 (+ complexity) on every create/reset path; set Supabase Auth min length to match.

#### H2 — Event-admin MFA unwired — **deferred**
1. **SEVERITY:** High  
2. **LOCATION:** `admin-setup/src/pages/Login.tsx:121-131`; `admin-setup/src/App.tsx:216-218`; `LoginMfa.tsx` / `cadminMfa.ts` (orphaned, not routed)  
3. **ISSUE:** Platform admins get email OTP; event admins are password-only. TOTP helpers exist but are not routed. Advisor: `auth_insufficient_mfa_options`.  
4. **IMPACT:** Stolen event-admin password → event console control.  
5. **FIX:** Require OTP/TOTP for all cadmin privileged roles; enforce server-side where possible.

#### H3 — Mobile / live-wall dependency highs
1. **SEVERITY:** High  
2. **LOCATION:** `docs/security-audits/2026-08-04-deps-preflight.md` — mobile **2 High** (postcss, sharp) + undici moderate; live-wall **3 High**; admin-setup **2 Moderate** (react-router)  
3. **ISSUE:** Tooling/supply-chain advisories; clean mobile path needs Expo major (`audit fix --force` breaking).  
4. **IMPACT:** Supply-chain / tooling risk; many issues limited runtime exploitability in production apps.  
5. **FIX:** Follow `DEPENDENCY-ADVISORY-PLAN.md`; schedule Expo major QA; bump react-router when ready.

### Medium Findings (Fix within 30 days)

#### M1 — Public R2 object URLs
1. **SEVERITY:** Medium (accepted for feed assets)  
2. **LOCATION:** Cloudflare R2 public object URLs  
3. **ISSUE:** URLs shareable if leaked.  
4. **IMPACT:** Unauthorized media view if URL obtained.  
5. **FIX:** Document threat model; signed URLs for sensitive assets.

#### M2 — Mobile login rate-limit fails **open**
1. **SEVERITY:** Medium (accepted for attendees)  
2. **LOCATION:** `lib/loginRateLimit.ts:32-70`  
3. **ISSUE:** Missing config / HTTP error / network → allow mobile sign-in (Sentry alert). **cadmin now fail-closed** (closed).  
4. **IMPACT:** During Edge outage, attendee lockout disappears while Auth still works.  
5. **FIX:** Keep as product choice, or fail-closed for higher-risk mobile roles only.

#### M3 — Co-member can SELECT email/phone (networking by design)
1. **SEVERITY:** Medium / Partial accept  
2. **LOCATION:** `users_select_scoped` RLS (live: authenticated-only); column privileges include email/phone  
3. **ISSUE:** Email/phone readable among co-members.  
4. **IMPACT:** PII within event trust boundary.  
5. **FIX:** Product decision — document or narrow via column grants / profile RPC.

#### M5 — Security Advisor DEFINER EXECUTE noise
1. **SEVERITY:** Medium (residual)  
2. **LOCATION:** Advisor **114** lints — ~85 authenticated DEFINER executable, ~21 anon DEFINER, 7 RLS-on/no-policy  
3. **ISSUE:** Large DEFINER surface if any body lacks authz.  
4. **IMPACT:** Privilege abuse if a DEFINER is under-checked.  
5. **FIX:** Continue grant minimization; document intentional live-wall RPCs.

#### M8 — Platform OTP UI skipped if `users` profile read fails — **NEW**
1. **SEVERITY:** Medium  
2. **LOCATION:** `admin-setup/src/App.tsx:208-218`  
3. **ISSUE:** `maybeSingle()` ignores `error`. Null/failed profile → treated as non–platform-admin → `setPlatformAdminGate('ok')` without email OTP. Exception path correctly goes `need_otp`; silent query miss does not.  
4. **IMPACT:** Transient RLS/network miss can open the admin shell without the email OTP step-up UI. Platform RPCs still need step-up server-side, but client console and dual-role paths may be reachable.  
5. **FIX:** On profile `error` or unexpected null for a known platform session: stay `need_otp` / sign out — never treat as non-platform-admin.

```typescript
const { data: profile, error } = await supabase
  .from('users')
  .select('is_platform_admin')
  .eq('id', sessionUserId)
  .maybeSingle();
if (error) {
  setPlatformAdminGate('need_otp');
  return;
}
```

#### M9 — Storage / registration uploads bypass R2 content validators — **NEW**
1. **SEVERITY:** Medium  
2. **LOCATION:** `lib/image.ts:566-587` (mobile Storage path); `admin-setup/src/pages/RegistrationPortal.tsx:263-286` (`vendor-attachments`, optional `data:` URL fallback)  
3. **ISSUE:** Primary mobile photos and registration attachments often upload to Supabase Storage with client-declared MIME; no magic-byte Edge check. Registration can store raw data URLs on failure.  
4. **IMPACT:** Authenticated users may place non-image bytes (or oversized data URLs) under allowed Storage paths / submission JSON.  
5. **FIX:** Route uploads through `upload-image-to-r2` or add Storage trigger/Edge verify; reject `application/octet-stream` and data-URL fallbacks for attachments.

### High Findings (Should Fix Before Launch)

#### H1 — Password policy still min 8 — **deferred by product**
1. **SEVERITY:** High (ASVS) / Accepted until revisit  
2. **LOCATION:** `app/(auth)/register.tsx:46-47`; `admin-setup/src/pages/RegistrationPortal.tsx:358`; Edge resets (`admin-reset-user-password`, `bulk-create-users`)  
3. **ISSUE:** Minimum password length is 8, not ASVS ≥12. Supabase Advisor also flags `auth_leaked_password_protection`.  
4. **IMPACT:** Weaker credential resistance against stuffing / guessing.  
5. **FIX:** Enforce ≥12 + complexity; enable HaveIBeenPwned / leaked-password protection in Supabase Auth.

#### H2 — Event-admin MFA unwired — **deferred (last)**
1. **SEVERITY:** High  
2. **LOCATION:** `admin-setup/src/App.tsx:215-217` (non–platform-admin skips OTP gate); `admin-setup/src/pages/Login.tsx`  
3. **ISSUE:** Platform admins get email OTP step-up; event admins are password-only. Advisor: `auth_insufficient_mfa_options`.  
4. **IMPACT:** Stolen event-admin password → full event console control.  
5. **FIX:** Require TOTP/OTP for all cadmin privileged roles (not only platform admin).

#### H3 — Mobile / live-wall dependency highs (SDK majors)
1. **SEVERITY:** High  
2. **LOCATION:** Preflight `docs/security-audits/2026-08-01-deps-preflight.md` — mobile **6 High**; live-wall **3 High** (postcss/sharp via Next); admin-setup **2 Moderate** (react-router)  
3. **ISSUE:** Clear Expo path is SDK 57 (`npm audit fix --force` is breaking). live-wall still reports transitive postcss/sharp highs on Next 15.5.22.  
4. **IMPACT:** Supply-chain / tooling advisories; limited runtime exploitability for many Metro/postcss issues, but not enterprise-clean.  
5. **FIX:** Follow `DEPENDENCY-ADVISORY-PLAN.md`; schedule Expo major QA; track Next/sharp advisories without downgrading Next.

#### H4 — `users.push_token` SELECT by `authenticated` — **closed (re-audit #6 follow-up)**
1. **SEVERITY:** High → Closed  
2. **LOCATION:** Was live ACL; fixed by `users_push_token_column_lockdown` (`20260801220000_…`)  
3. **ISSUE (was):** Table-level `ALL` made column `REVOKE` ineffective.  
4. **IMPACT (was):** Co-member push-token harvest.  
5. **FIX (done):** Revoked table privileges; granted SELECT allowlist excluding `push_token` / `password_reset_blocked`; UPDATE retained on `push_token` for device registration. Live check: `push_sel=false`, `push_upd=true`.

### Medium Findings (Fix within 30 days)

#### M1 — Public R2 object URLs
1. **SEVERITY:** Medium (accepted for feed assets)  
2. **LOCATION:** Cloudflare R2 public bucket URLs used by clients  
3. **ISSUE:** Object URLs are guessable/shareable if leaked.  
4. **IMPACT:** Unauthorized viewing of media if URL obtained.  
5. **FIX:** Document threat model; consider signed URLs for sensitive assets.

#### M2 — Client-shipped `LOG_AUTH` secret (obscurity)
1. **SEVERITY:** Medium  
2. **LOCATION:** `EXPO_PUBLIC_LOG_AUTH_ATTEMPT_SECRET` / `VITE_LOG_AUTH_ATTEMPT_SECRET`  
3. **ISSUE:** Shared Edge secret ships in clients; rotated and removed from committed `eas.json`, but extractable from builds.  
4. **IMPACT:** Attacker can invoke rate-limit / auth-log endpoints (still need to understand API); not a full auth bypass.  
5. **FIX:** Move to Supabase Auth hooks / server-only callers; ensure EAS env set for next mobile build.

#### M3 — Co-member can SELECT email/phone (networking by design)
1. **SEVERITY:** Medium / Partial accept  
2. **LOCATION:** `users` RLS for event co-members  
3. **ISSUE:** Email/phone readable among co-members for B2B networking.  
4. **IMPACT:** PII exposure within event trust boundary.  
5. **FIX:** Product decision — keep documented; or narrow to opt-in / admin-only fields.

#### M4 — `process-scheduled-announcements` CORS `*` — **closed (redeployed v28)**
1. **SEVERITY:** Medium → Closed  
2. **LOCATION:** Was local shadowed `corsHeaders()`; now shared allowlist only  
3. **ISSUE (was):** `Access-Control-Allow-Origin: *` via shadowing.  
4. **IMPACT (was):** CORS policy fail on cron fn.  
5. **FIX (done):** Removed local CORS; uses `_shared/cors.ts`; Edge version **28**.

#### M5 — Security Advisor DEFINER EXECUTE noise
1. **SEVERITY:** Medium (mostly informational / residual)  
2. **LOCATION:** Supabase Security Advisor — **112 WARN** (`authenticated_security_definer_function_executable` ×86, `anon_security_definer_function_executable` ×24, plus auth MFA/leaked-password); **7 INFO** `rls_enabled_no_policy`  
3. **ISSUE:** Many SECURITY DEFINER RPCs remain executable by `anon`/`authenticated` (includes intentional live-wall RPCs).  
4. **IMPACT:** Attack surface if any DEFINER body lacks authz checks.  
5. **FIX:** Continue grant minimization; audit each anon-callable DEFINER; leave intentional public live-wall RPCs documented.
